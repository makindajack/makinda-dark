## 🚚 Migration

This standalone `makindajack.makinda-dark` extension has been merged into a unified package:

> **[Makinda Themes](https://marketplace.visualstudio.com/items?itemName=makindajack.makinda-themes)** — `makindajack.makinda-themes`

Install the new extension and you'll get both Makinda Light and Makinda Dark in a single package, with shared updates and a single Marketplace listing.

### How to migrate

```bash
# Install the new combined extension
code --install-extension makindajack.makinda-themes

# Uninstall this deprecated one
code --uninstall-extension makindajack.makinda-dark
```

Then open the Color Theme picker (`⌘K ⌘T` / `Ctrl+K Ctrl+T`) and select **Makinda Dark**.

---

## Why?

Combining Light and Dark into one extension means:

- One install for both variants
- One place for issues, releases, and changelog
- Shared brand language and consistent updates
- Easier to add automatic light/dark switching with `window.autoDetectColorScheme`
